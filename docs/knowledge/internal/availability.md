# Data Acquisition Method Matrix for the Internal ASTRA Database

**Status:** `research_only`, verified 2026-11-07. The class describes the confirmation of the **data acquisition method**, not the connection to ASTRA. For all onboard and suit-based data streams, the direct local ASTRA interface is **not confirmed**; the current program accepts manual entries. Classes are defined in [README](README.md#how-to-read-access-classes). Sources, dates, and limitations are added in [registry](source-ledger.md).

## Units, Time, and Quality

For each future record, one unit of the **source device** is required, along with UTC time of measurement and a separate time of entry. For a series and interval, start, end, and aggregation method are recorded. For this research package, the following *types* of units are provided; they do not imply the presence of a stream or threshold.

| ID | Unit or format; temporal basis | Minimum context of quality |
|---|---|---|
| `M.heart_rate`, `M.respiratory_rate` | `bpm`, `breaths/min`; moment or named interval | Rest/effort, device, artifacts |
| `M.spo2`, `M.blood_pressure` | `%`, `mmHg` (systolic and diastolic separately); moment | Device, method, posture/effort, signal quality |
| `M.skin_temperature`, `M.body_temperature`, `M.estimated_core_temp` | `°C`; moment/interval | Location and method, direct value or calculated estimate |
| `M.actigraphy_motion`, `M.activity_sensor` | Raw axes/count from device and frequency per specification; interval | Device, algorithm, wear period and gaps; universal unit not established |
| `M.sleep_timing_derived`, `M.sleep_timing_report` | UTC start/end and duration `h`; episode | Algorithm or person's words, time zone shift, night/day shift work |
| `M.self_report` | Text or named version of scale; time of message and period it refers to | Question wording, author, privacy; scale not assumed in advance |
| `M.vision_function`, `M.ocular_imaging` | Indicator and unit depend on approved test/device; session date, eye separately | Calibration, distance, correction, operator, method; universal unit not established |
| `M.body_mass`, `M.exercise_record` | `kg` at SLAMMD; duration `min` and specific trainer parameters per session | Method, configuration, repetitions, gaps |
| `M.cabin_environment`, `M.cabin_atmosphere` | CO₂ in raw concentration from device, temperature `°C`, humidity `%`, pressure in raw unit; point/interval | Sensor, calibration, compartment, averaging; units of specific telemetry to be specified upon import |
| `M.noise_air_quality` | Depends on measured quantity and device; interval | No single composite indicator or confirmed scheme |
| `M.personal_dose`, `M.cabin_radiation` | Dose and dose rate in original units of the specific dosimeter; interval | Type of quantity, device, calibration, personal/ambient source |
| `M.eva_hr_co2`, `M.eva_other` | Pulse `bpm`; CO₂ and other fields in original units of the selected system; interval | Version of suit, channel, delay, gaps; format for other fields is not defined |
| `C.mission_operations` | UTC events and durations `h`/`min`; phase as code | Source of schedule, time zone shift, corrections |

## First usable version and honest limitations

**Core:** manual pulse, breathing, SpO₂, pressure and temperature with method/conditions; complaints and sleep as human messages; manually assigned phase/load. Since the current form does not collect part of this context, the document describes **requirements for the next version**, and not that comparisons already fully account for it. Descriptive environmental data can be added only as sensor records with date, location, time and source.

**Follow-up:** calibrated repeated vision test and original series, training data, body weight, personal dosimeter and import of ecological series with proven access. **Do not consider as available:** all onboard flows for ASTRA, any "common" suit flow, continuous body pressure/temperature assessment, universal air index and automatic detection of psychological state. A research device on one crew does not imply standard equipment for each mission.
